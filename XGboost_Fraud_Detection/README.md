## Overview

An end-to-end financial AI system combining **market time-series, technical indicators, and deep learning** for financial risk prediction.

### Key Components

- 📈 Market time-series modeling
- 🧮 Technical & statistical feature engineering
- 🧠 Transformer-based temporal modeling
- 🌲 LightGBM baseline
- 🔬 MLflow experiment tracking
- ⚡ FastAPI model serving
- ☁️ Databricks & Spark pipelines
- 🐳 Dockerized deployment
